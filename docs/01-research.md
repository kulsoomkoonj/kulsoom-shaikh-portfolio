Sources used: [Nicolai Nielsen — AI engineering portfolio](https://nicolainielsen.dev/blog/build-an-ai-engineering-portfolio), [Aiporate — what a great AI portfolio looks like](https://talents.aiporate.com/blog/ai-engineer-portfolio-what-to-look-for), [Square1 — portfolios hiring managers read](https://www.square1ai.com/research/how-to-build-an-ai-portfolio-hiring-managers-read), [Skilling — recruiter-scan ML sites](https://skilling.pro/how-to-create-a-machine-learning-portfolio-website-that-recruiters-can-scan-fast), [GenAI portfolio guide](https://myengineeringpath.dev/genai-engineer/portfolio-guide/), [Refolk artifact reference](https://www.refolk.ai/guides/ai-engineer-llm-artifact-reference), [Linear/Vercel design roundups](https://toimi.pro/blog/best-saas-website-designs/), [Next.js SEO checklist](https://bipanshu.in/blog/nextjs-portfolio-seo-checklist).

## What recruiters actually scan for (under 30 seconds)

1. Who you are and **which role** you want.
2. Two to four **proof projects**, not sixteen cards.
3. A number: eval, latency, win-rate, hours in production — with honesty.
4. How to contact you (email, LinkedIn, GitHub, CV).

## What to stop doing (old site)

- Purple galaxy, 3D orbs, custom cursor, splash loader, emoji-heavy cards.
- Chatbot that invents answers about you.
- A wall of skills with no levels.
- Case studies that only list tech names.
- Direct `/skills` 404 because the SPA had no rewrites.

## What to put on an AI/agent engineer site in 2026

| Block | Why the market wants it |
| --- | --- |
| Clear role line | “Agentic AI & LLM engineer” not “passionate coder” |
| 3–5 case studies | Problem, constraints, architecture, evidence, limits |
| MCP + tool-use proof | High-scarcity skill if it is *your* server, not a fork |
| RAG with eval talk | Faithfulness / citations / what failed |
| Production or paper-test metrics | OmniTrader: simulated PF 1.4, 50h, not live profit |
| Experience + education | Sukkur IBA, MS in progress, freelance 56+ |
| Certifications with verify links | Bedrock, MCP Advanced, Azure NLP, micro1 |
| Contact that works | Form or mailto + calendar later |
| Fast, accessible, SEO | LCP < 2.5s, skip link, Person JSON-LD |

## Proof mix we already have

- **Agent / MCP:** S3 MCP, WhatsApp MCP bot, CALIX.
- **RAG:** StudyPilot / Agentic RAG.
- **Eval:** Seq2Seq BLEU, OmniTrader paper test (labelled simulated).
- **Product:** Glow salon bot, AI-CDSS, ClinNote AI.
- **Full stack:** Angular / React / .NET at the software company.

## Do not ship on v1

Site-wide AI chatbot, 3D hero, private-repo cloning, phone number, live GitHub token in the browser, fake “LIVE trading” claims.
