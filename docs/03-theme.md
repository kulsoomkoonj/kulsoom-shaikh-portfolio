# Theme — light studio (Bootstrap + Tailwind)

White paper background, indigo accent `#4F46E5`, Fraunces display + Outfit body.
The old `Hu.png` file is a QR code, not a portrait. The site logo is the HS monogram in `public/brand/logo.svg`.

Bootstrap supplies navbar, cards, accordion, and modals. Tailwind utilities sit on top without Preflight so the two systems do not reset each other.
